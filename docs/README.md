This export keeps the shared research from the original multi-game workspace,
so several pages here describe **Smash Hit** rather than PinOut. They are
listed separately below. `unknowns.md` starts with Smash Hit and ends with the
limits recorded for Granny Smith and PinOut. `mediocre_comparison.md`,
`other_game_devkits.md`, `native_scene_editor.md`, `game_lab_experiments.md`
and the root notebook cover more than one game.

Only `labs/pinout/` ships here as the game-specific Lab adapter. Commands
for another adapter need that game's repository.

Historical PASS and CONFIRMED labels refer to the builds named in their own
reports. Raw evidence and some referenced pages were left out of the export, so
a page named in one of these notes may not exist in this checkout. The root
README has the current setup commands.
